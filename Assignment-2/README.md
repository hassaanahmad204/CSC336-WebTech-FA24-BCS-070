Assignment 2 — Responsive E-Commerce Site

Reference Site Details

Site Name: Apple Store

Full URL: https://www.apple.com/store

About the Project

This project is a static, responsive front-end clone modeled on the minimalist design system of the official Apple Store. It features an 8-product catalog grid on the homepage and a dedicated MacBook Pro detail page complete with hardware specifications, configuration options, and a quantity selector. Built using Bootstrap 5 and semantic HTML5, the entire layout dynamically reflows across phone (~375px), tablet (~768px), and desktop viewports.
